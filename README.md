# 🤖 بوت التوظيف السعودي

بوت تليجرام ذكي لمساعدة الباحثين عن عمل في المملكة العربية السعودية.

---

## 📁 هيكل المشروع

```
saudi_jobs_bot/
├── main.py                    ← نقطة البداية الرئيسية
├── requirements.txt           ← المكتبات المطلوبة
│
├── config/
│   └── settings.py            ← إعدادات البوت والثوابت
│
├── database/
│   └── db.py                  ← قاعدة البيانات وجميع العمليات
│
├── handlers/
│   ├── registration.py        ← خطوات إنشاء الملف الشخصي
│   └── callbacks.py           ← معالج جميع الأزرار
│
├── keyboards/
│   └── keyboards.py           ← لوحات المفاتيح Inline
│
└── utils/
    └── notifier.py            ← نظام الإشعارات ومطابقة الوظائف
```

---

## 🚀 طريقة التشغيل

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. إنشاء بوت تليجرام
- افتح @BotFather في تليجرام
- أرسل `/newbot`
- اتبع الخطوات واحصل على **TOKEN**

### 3. إعداد الإعدادات
افتح `config/settings.py` وعدّل:
```python
BOT_TOKEN = "1234567890:ABCdefGHIjklMNOpqrSTUvwxYZ"  # ← توكن البوت
CHANNEL_ID = "@your_jobs_channel"                       # ← معرف القناة
```

### 4. إضافة البوت للقناة
- اذهب لإعدادات القناة
- أضف البوت كـ **Admin** مع صلاحية قراءة الرسائل

### 5. تشغيل البوت
```bash
python main.py
```
